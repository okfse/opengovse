# Brand assets

Sweden-localized Open Knowledge Sverige logos for opengov.se.

Vendored in-repo under `assets/brand/se/`. The former [assets.okfn.se](https://github.com/okfse/assets.okfn.se) repository is no longer the source.

## Layout

```
se/
├── Landscape/   OKSE-landscape-{white,black,grey,full}-rgb  (1x–4x + SVG)
├── Portrait/    OKSE-portrait-{white,black,grey,full}-rgb   (1x–4x + SVG)
├── No text/     OK-notext-{white,black,grey,full}            (1x–4x + SVG)
├── favicon-32.png
└── apple-touch-icon.png
```

## Used on opengov.se

| Use | File |
|-----|------|
| Footer (dark background) | `Landscape/SVG/OKSE-landscape-white-rgb.svg` |
| Favicon | `favicon-32.png` (generated from `No text/OK-notext-full`) |
| Apple touch icon | `apple-touch-icon.png` (generated from `No text/OK-notext-full`) |

Header uses the `opengov.se` text wordmark only.

## Variants

- **Landscape** — horizontal logo with wordmark; use white on dark backgrounds, black on light
- **Portrait** — stacked layout
- **No text** — mark only; suitable for favicons and compact placements
- **full** — full colour; **white**, **black**, **grey** — monochrome variants
